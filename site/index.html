Quick start

Your next codebase, a little clearer.

1. Install the extension

Search for Ducktor in the VS Code marketplace. Or download a VSIX from GitHub Releases and run Extensions: Install from VSIX....

VS Code Marketplace ↗Releases ↗

Open your project folder in VS Code. Enable Inlay Hints, Hover, and CodeLens:

{
  "editor.inlayHints.enabled": "on",
  "editor.hover.enabled": true,
  "editor.codeLens": true
}

2. Load the generator skill

Place the entire skill directory in a location supported by your AI host, including references/. Or install with OpenSkills (requires Node.js):

npx openskills install ZoruaSama/Ducktor
npx openskills sync

Select ducktor-generator when prompted. sync registers it for agents that read AGENTS.md; other hosts use their own loading conventions.

Then ask your AI agent:

Generate L3 Ducktor explanations for
src/main.js in English, with verified
references to related symbols.
Good to know

A few practical details.

Does the extension generate explanations?

No. Generation is handled by your AI host using the Ducktor generator skill. The extension reads and displays existing explanations and needs no model or API-key configuration. You can also write the files manually.

Where do explanation files go?

Mirror source paths under the workspace-root .ducktor/ directory and append .ducktor. For example, src/main.js maps to .ducktor/src/main.js.ducktor. Files next to the source are not read. Each folder in a multi-root workspace has its own explanation directory.

How do I open the reading views?

Hover a Ducktor hint or underlined term. Use the top-of-file CodeLens when valid line explanations exist. To browse the project, run Ducktor: Open File Explorer from the command palette. Set ducktor.displayMode to panel for the right-hand panel.

Can explanations be in Chinese?

Yes. Request the explanation language during generation. Set ducktor.language to zh-CN for the extension's localized interface. This setting does not translate existing explanation content.

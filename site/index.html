Install it yourself

1. Install the extension

Ducktor is not yet published to the VS Code Marketplace. Download the latest .vsix from GitHub Releases. In your IDE, open the command palette and run Extensions: Install from VSIX..., then select the downloaded file.

Download VSIX from Releases ↗Try the preview →

Open your project folder in VS Code. Press Ctrl + Shift + P (macOS: ⌘ + Shift + P) to open the command palette. Search directly for these keywords, select the corresponding toggle command, and make sure each feature is enabled:

  • hover: enable hover tooltips.
  • codelens: enable CodeLens.
  • inlay hints (or inline hints): enable inline hints.

Alternatively, open the command palette and search for Preferences: Open User Settings (JSON). Merge the following into your existing settings without replacing other entries:

{
  "editor.inlayHints.enabled": "on",
  "editor.hover.enabled": true,
  "editor.codeLens": true
}

2. Install the generator skill

OpenSkills installation: use OpenSkills to install the complete skill. First install Node.js LTS (includes npm), then install OpenSkills in your terminal:

npm install -g openskills

Install globally into the universal Agent skill directory under your home directory (~/.agent/skills/). --global selects global installation; --universal selects the shared directory. Using only --universal is not a global installation.

openskills install ZoruaSama/Ducktor --global --universal

Update this skill later:

openskills update ducktor-generator

For agents that load skills through AGENTS.md, run this registration command in the relevant project (it does not reinstall the skill into the project):

openskills sync

Select ducktor-generator when prompted. sync registers it for agents that read AGENTS.md; other agents use their own loading conventions.

Manual installation: download or clone the repository, then copy skills/ducktor-generator/ as a complete directory, including SKILL.md and references/.

  • Codex: ~/.codex/skills/ducktor-generator/
  • Claude Code: ~/.claude/skills/ducktor-generator/
  • Cursor: ~/.cursor/skills/ducktor-generator/

These are global skill paths under your home directory (~), not your project directory. Restart or reload your agent if required. If skills are not discovered, ask the agent to read skills/ducktor-generator/SKILL.md from your cloned repository and follow it.

Browse your project

The File Explorer.

Need an overview of every file that has Ducktor explanations? Open the Ducktor File Explorer from the command palette. It shows your entire explained project at a glance, without leaving VS Code.

How to open it

Press Ctrl + Shift + P (macOS: ⌘ + Shift + P), type Ducktor, and run Ducktor: Open File Explorer / 打开文件目录. The command ID is ducktor.showIndex.

Need to open it again? Just search for Ducktor — it sits right next to all the other Ducktor commands in the palette.

What you can do

  • Browse every explained source file in its original directory structure
  • Expand any file to see its line-by-line explanations, code blocks, and term definitions
  • Click any entry to jump straight to the corresponding source line
  • Filter to files that have line explanations, diagrams, or both
  • Search file names to quickly locate what you need

Good to know

A few practical details.

Does the extension generate explanations?

No. Generation is handled by your AI agent using the Ducktor generator skill. The extension reads and displays existing explanations and needs no model or API-key configuration. You can also write the files manually.

Where do explanation files go?

Mirror source paths under the workspace-root .ducktor/ directory and append .ducktor. For example, src/main.js maps to .ducktor/src/main.js.ducktor. Files next to the source are not read. Each folder in a multi-root workspace has its own explanation directory.

How do I open the reading views?

Hover a Ducktor hint or underlined term. Use the top-of-file CodeLens when valid line explanations exist. To browse the project, run Ducktor: Open File Explorer from the command palette. Set ducktor.displayMode to panel for the right-hand panel.

Can explanations be in Chinese?

Yes. Request the explanation language during generation. Set ducktor.language to zh-CN for the extension's localized interface. This setting does not translate existing explanation content.

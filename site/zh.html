快速开始

让下一个代码库，更容易读懂。

1. 安装 VS Code 插件

在 VS Code 插件商店搜索 Ducktor。也可以从 GitHub Releases 下载 VSIX，在命令面板运行 Extensions: Install from VSIX... 安装。

VS Code 插件商店 ↗下载 Releases ↗

在 VS Code 中打开项目文件夹，并开启 Inlay Hints、Hover 和 CodeLens：

{
  "editor.inlayHints.enabled": "on",
  "editor.hover.enabled": true,
  "editor.codeLens": true
}

2. 加载生成 skill

将整个 skill 目录放到 AI 宿主支持的位置，包含 references/。也可用 OpenSkills 安装（需要 Node.js）：

npx openskills install ZoruaSama/Ducktor
npx openskills sync

出现提示时选择 ducktor-generator。sync 为读取 AGENTS.md 的 Agent 注册 skill；其他宿主遵循各自的加载约定。

然后向 AI Agent 发出请求：

为 src/main.js 生成 L3 Ducktor 解释，
使用中文，并为相关符号补充
可核实的引用。
使用前的小提示

几个实用问题。

插件会自动生成解释吗？

不会。生成由使用 Ducktor generator skill 的 AI 宿主完成。插件只读取和展示已有解释，无需配置模型或 API Key。你也可以手写解释文件。

解释文件应该放在哪里？

在工作区根 .ducktor/ 目录下镜像源码路径，再追加 .ducktor 扩展名。例如 src/main.js 对应 .ducktor/src/main.js.ducktor。插件不读取源码旁的解释文件；多根工作区中的每个文件夹分别维护解释目录。

怎样打开不同的阅读视图？

悬停 Ducktor 行末提示或带下划线的术语；存在有效逐行解释时，使用文件顶部的 CodeLens。浏览项目可在命令面板运行 Ducktor: Open File Explorer / 打开文件目录。将 ducktor.displayMode 设为 panel 可使用右侧面板。

可以生成中文解释吗？

可以。在生成请求中明确正文语言。将 ducktor.language 设为 zh-CN 可使用插件的中文界面；该设置不会翻译已有解释正文。

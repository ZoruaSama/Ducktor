# 生成与更新检查清单

将格式有效、源码一致与语义质量分别检查；YAML 可解析不代表解释正确。

## 1. 写入前：依据与范围

- 确认工作区根、源码路径、当前源码版本、输出范围、等级与最终能力。
- 已读取源码与相关定义；所有事实、符号、成员和引用有依据。
- 已读取已有解释，保留范围外内容；没有擅自修改源码或扩大输出范围。
- 块以明确逻辑单元组织，没有不必要的嵌套重复；锚点与块起点一致。

## 2. 解析与字段

使用可用的真实 YAML 解析器。优先项目已有安全解析入口；没有时使用环境已有 YAML 库。不要依赖插件会静默丢弃错误项。

- 输出为 UTF-8，顶层对象含 blocks 与 terms 列表，无重复键或未知生成字段。
- 每块 range 格式合法、content 为非空字符串。
- 实际范围满足 1 ≤ start ≤ end ≤ 源码行数；`"*"` 对应全文件。
- anchor 形式、类型、name/value 正确且真实；hash 已确认算法并实际计算。
- lines 为列表，line 是整数，范围内、不重复、升序；content 为非空字符串。
- terms 的 symbol、content 为非空字符串，scope 合法。
- local 的 block 是 1 到 blocks 原始列表长度内的整数，对应启用且有效块。
- aliases/tags 为字符串列表，enabled 为布尔值；term type 不误用 anchor 枚举约束。

若环境缺少 YAML 解析器，不能把手工检查称为已解析验证。说明阻碍，取得合适校验环境后完成；不要未检查就宣称文件有效。

## 3. 源码位置与更新

- 镜像文件路径与源码严格对应，不位于源码旁或错误工作区。
- 写入前已自行创建缺失的工作区根 `.ducktor` 及目标镜像父目录，保留已有内容，没有建立与本次输出无关的目录。
- 行号基于当前源码，不是 diff；range、锚点、逐行说明一致。
- 内部增删行后已重算 lines；块排序/增删后已同步 local block。
- 不同块不重复占用同一行的逐行说明。
- D 已逐行对照：所有有意义行均覆盖，空行和纯结构收尾可跳过；部分格式示例不能当作完整覆盖。

## 4. 引用与安全

- 符号链接目标已确认；歧义目标优先文件行范围。
- 文件/文档路径相对源码所在目录，解析后在工作区内，目标存在、行号有效。
- URL 是真实提供或核实的地址，没有示例占位地址、按标题伪造的尖括号链接。
- 没有危险协议、HTML、自定义术语/块协议或未授权命令。
- 没有假定符号跳转等于打开已有解释，或 terms 在正文自动弹出。
- 各层正文实质性提到相关实现时提供必要引用，未过度重复链接。

## 5. 语义与分层

- A 说明职责和结果；B 覆盖重要契约；C 清楚呈现阶段与条件。
- D 解释局部动作与数据含义，不机械翻译语法。
- E 短而必要，作用域正确；F 默认只介绍当前函数涉及的成员。
- G 有位置和依据，区分事实与风险，不虚构缺陷。
- 没有虚构设计动机、业务规则、异常、性能或安全保证。
- content、lines、terms 相互补充，不整段复制；引用不替代解释。

## 6. 写入后

重新读取/解析实际落盘文件，重复结构与位置检查。有现成插件解析入口及校验工具时可验证插件接受输出，但不要为此启动 UI 或修改插件。只有实际做过渲染验证才报告渲染成功。

交付时报告生成位置、范围、等级与能力、验证结果以及未确认项；未覆盖的依赖或没有来源的设计动机如实说明，不强行补齐。
